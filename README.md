# 작은 스시집 · 8인 멀티플레이

## 실행

Node.js 18 이상 설치 후 이 폴더에서:

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`에 접속합니다. 같은 컴퓨터에서 탭 여러 개를 열어 시험할 수 있습니다. 같은 와이파이의 다른 기기는 서버 컴퓨터의 사설 IP 주소와 포트 3000으로 접속합니다. 인터넷 공개 플레이는 포트 개방 또는 Node.js/WebSocket 지원 호스팅과 HTTPS/WSS 설정이 필요합니다.

## 조작

- 입장 시 닉네임과 아바타 색상 선택
- `셰프 맡기` → 썰기(스페이스) → `접시 내놓기`
- 손님은 `썬 참치 먹기`로 들어가 간장, 와사비, 젓가락과 참치 상호작용
- `자리 넘기기`로 셰프 역할 해제
- 채팅창에서 메시지 전송

## 현재 구현 범위와 주의점

- 서버는 한 명의 셰프만 허용하며 참치 재고/접시 수량/접속자/채팅을 공유합니다.
- 3D 식사 장면과 카메라 조작은 각자 로컬에서 진행됩니다. 다른 손님의 손/칼/먹기 애니메이션을 실시간 3D로 복제하지는 않습니다.
- 접시의 개수는 서버가 판정하지만 소비 동작 완료 후 보고하므로, 동시에 먹을 때 로컬 연출과 서버 수량이 잠시 달라질 수 있습니다.
- 셰프가 썬 참치의 3D 칼 동작은 다른 손님 화면에 재생되지 않고 공유 재고만 반영됩니다.
- 서버 재시작 시 재고와 채팅 기록이 초기화됩니다. 로그인/비밀번호/영구 저장은 없습니다.
- 기존 HTML은 외부 Three.js CDN을 사용하므로 최초 로드에 인터넷 연결이 필요합니다.
