# 작은 스시집 V6 — 말풍선 · 몰래 집어먹기 · 회 수량 정확화

V5 실시간 회 썰기 / 8인 방 / 셰프 역할 / 개인 테이블 / 간장·와사비·사케 상호작용에 기능을 추가한 업데이트입니다. 휴대전화에서는 이전 모바일 최적화 버전처럼 채팅과 접속자 목록이 접히도록 구성했습니다.

## 이번 업데이트

### 1) 아바타 말풍선
- 채팅을 보내면 **발신자의 3D 아바타 머리 위**에 5.5초간 말풍선이 나타납니다.
- 말풍선은 3D 카메라에 맞추어 회전하는 스프라이트입니다. 1~2줄만 표시하므로 긴 메시지는 줄임표로 축약되고, **전체 메시지는 기존 채팅창에서** 볼 수 있습니다.
- 같은 방의 모든 접속자에게 동일하게 적용합니다. 채팅 기록은 방 외부에 전송하지 않습니다.

### 2) 셰프가 손님 접시에서 몰래 집어먹기
- 셰프일 때만 **접속자 목록의 해당 손님 옆 `몰래 한 점`** 버튼을 누르세요.
- PC에서는 상단 **`쉿, 한 점`** 단축 버튼으로 손님들을 번갈아 선택하거나, 가게 전경에서 **손님 접시를 직접 클릭**할 수도 있습니다.
- 손님 접시에 실제 참치가 1점 이상 있어야 합니다. 서버에서 손님 접시 **-1점**, 셰프의 몰래 먹은 수량 **+1점**으로 확정합니다.
- 채팅이나 시스템 공지로 도둑질을 알리지 않습니다. 다만 주의 깊게 보면 **손님 접시에서 셰프 쪽으로 이동하는 회**가 보입니다.
- 손님이 자기 접시를 먹고 있는 중에도 다른 손님의 회는 영향을 받지 않습니다. 연속 도둑질에는 1.1초 간격 제한이 있습니다.
- 손님이 있으면 썬 회를 **손님들에게만** 분배하고, 셰프 혼자 있을 때는 이전처럼 자기 접시에 받을 수 있습니다.

### 3) 썬 조각과 접시 수량 일치
- 서버에서 절단 완료된 **1회 = 참치 1점**입니다.
- 회 제공 시 그 정확한 수의 조각을 손님들 개인 접시에 **중복 없이** 배분합니다. 손님 한 명이면 전부 그 손님 접시에 놓입니다.
- 개인 테이블의 3D 회는 한 점당 한 개의 `InstancedMesh` 인스턴스로 그립니다. 기존의 `최대 12점까지만 표현` 제한을 제거했습니다.
- 식사 1인칭 화면의 회도 12점 제한을 없애고, 12점을 넘을 때 층층이 쌓이도록 변경했습니다.
- 소비 / 몰래 먹기 / 접속 종료에 따른 수량 변화를 서버에서 관리합니다.

### 4) 시식 대사 확장
- 간장+와사비, 와사비만, 간장만, 아무것도 없이 먹는 경우를 구분합니다.
- 식감·지방의 고소함·단맛·향·뒷맛을 느끼는 요리만화풍 신규 대사를 20개 이상 추가했습니다.
- 기존 요리만화식 컷인 연출과 사케 대사도 유지합니다.

## GitHub / Render 업데이트

기존 GitHub `sushi-bar` 저장소의 **최상위**에 압축파일 속 다음 파일을 업로드하고 기존 파일을 덮어쓰세요:

- `index.html`
- `server.js`
- `multiplayer.js`
- `package.json`
- `README.md`

**HTML만 교체하면 안 됩니다.** `server.js`와 `multiplayer.js`도 함께 교체해야 말풍선·몰래 먹기·수량 동기화가 동작합니다.

GitHub에서 `Commit changes` 하면 자동 배포가 켜진 Render Web Service가 업데이트됩니다. 별도의 Render 서버는 필요 없습니다. 배포 후 친구들도 브라우저를 새로고침하세요.

Render 배포 설정: **Web Service · Node · Build `npm install` · Start `npm start` · Root Directory 공란**. 로컬 실행: `npm install` → `npm start` → `http://localhost:3000`.

## 검증 범위

- 서버 가상 WebSocket 테스트에서 **14점 절단 → 손님 1명에게 14점 제공 → 셰프가 1점 몰래 먹기 → 손님이 1점 먹기 → 남은 12점** 검증.
- 서로 다른 방 분리, 셰프 권한 검증, 접속자 8명 상한, 임의 방 코드, 리셋 후 회 보존, 채팅 발신자 ID, 조리 동기화도 서버 테스트 통과.
- HTML의 인라인 JS·`multiplayer.js`·`server.js` Node 구문 검사 통과.
- **실제 3D 브라우저 시각 테스트는 테스트 환경의 로컬 브라우저 URL 접근이 막혀 실행하지 못했습니다.** Render 배포 후 2개 브라우저/PC·모바일에서 말풍선 위치와 접시 클릭을 확인해 주세요.
- 서버 재시작이나 Render 절전으로 메모리 상의 방 상태는 초기화됩니다.
