# 작은 스시집 — 3D 참치 썰기 · 8인 방 코드 멀티플레이

기존 `참치 썰고 간장·와사비 먹기` 3D 화면을 유지하면서 방 코드 입장, 3D 미니 아바타, 서버 공유 참치 접시와 셰프 교대를 추가한 버전입니다.

## 설치 및 배포

- Node.js 18 이상 환경에서 `npm install` 후 `npm start`
- 브라우저 주소: http://localhost:3000
- Render: **New → Web Service** (Static Site가 아님). Node 런타임, `main` 브랜치, Root Directory 공란, Build Command `npm install`, Start Command `npm start`. Render는 `PORT` 환경변수를 자동 제공합니다.
- GitHub에 이미 이전 버전을 올렸다면 이번 ZIP에서 `index.html`, `server.js`, `README.md`를 **교체**하고, `multiplayer.js`를 **추가**합니다. `package.json`은 그대로 덮어써도 됩니다.
- Render 자동 배포를 사용하면 GitHub에 커밋 후 재배포됩니다. 아니면 Render의 수동 배포 기능을 사용하세요.

## 방 입장

1. 닉네임과 아바타 옷 색상을 정합니다.
2. 직접 원하는 방 코드를 입력하고 `입장 / 방 만들기`를 누릅니다. 방이 없다면 **자동으로 생성**, 이미 있다면 **그 방에 입장**합니다. `1`, `A20261`, `우리집`, `친구랑 스시!` 같은 코드도 사용 가능합니다.
3. 코드를 직접 정하기 싫으면 `새 방 만들기`를 눌러 임의의 코드를 발급받을 수도 있습니다.
4. 상단의 `코드 복사`로 친구에게 알려주면 친구는 **동일한 코드**를 입력해 같은 방에 입장할 수 있습니다. 영문은 대소문자를 구분하지 않습니다.
5. 방마다 **8명 정원**이며, 각각의 방은 채팅·셰프·참치 수량이 독립입니다.

## 게임 방법

- `셰프 맡기`: 방에서 한 사람만 셰프 역할 가능
- `썰기`: 3D 회 썰기 (원래 조작 유지)
- `회 먹기`: **셰프라면 썰어 놓은 회를 자동으로 내놓은 다음 식사로 이동** — 역할을 내려놓을 필요 없음
- `접시 내놓기`: 다른 손님도 먹도록 남은 썬 회 제공
- `자리 넘기기`: 썰어 놓은 회가 있으면 자동으로 제공하고 셰프 해제
- `새 참치 준비`: 새 참치 블록으로 계속 썰기 가능; 이전에 썰어 둔 회는 자동으로 제공됨. 이미 내놓은 회는 삭제하지 않음
- 손님도 `회 먹기`로 공동 접시의 회를 먹으며, 간장·와사비·사케 3D 상호작용은 원본 유지
- 카운터 앞: 최대 8명의 색상 옷 미니 아바타가 나란히 서고, 셰프는 반대편 조리 자리에서 보임

## 현재 구현 범위와 제약

- 역할과 방 코드는 서버에서 판정하므로 다른 방 사람이 회를 먹거나 역할을 선점할 수 없습니다.
- 3D 아바타는 닉네임, 색상, 역할에 따라 카운터에 표시되는 **정적 미니어처 인형**입니다. 다른 사람의 칼질·손동작·식사 모션은 아직 3D 동기화되지 않으며 접시 수량과 역할만 실시간 동기화됩니다.
- 각자가 보는 식사 장면은 독립 3D 뷰이며, 서버는 먹은 회의 숫자를 공유합니다. 동시에 마지막 한 점을 먹는 등의 경합 상황에서는 한쪽의 시각적 소비가 서버에서 거부될 수 있습니다.
- 원하는 방 코드(1~64글자, 한글·영문·숫자·공백·기호 가능)로 입장합니다. 기존 방이 없으면 자동 생성됩니다. 같은 코드를 입력한 사람들은 같은 방에 들어갑니다. 서버를 재시작하면 기존 방은 사라지지만, 원하는 코드를 다시 입력해 새로 열 수 있습니다.
- 방은 마지막 접속자가 나가면 삭제됩니다. 서버를 재시작하면 방 코드, 채팅, 재고 모두 사라집니다. 로그인 인증 기능이 아니고, 코드를 아는 사람이 입장할 수 있는 가벼운 비공개 방입니다.
- Render의 무료 플랜은 대기 후 잠들거나 재시작할 수 있습니다. 새 배포·재시작 시 진행 중이던 세션은 사라집니다.
- 화면은 Three.js 0.128.0 CDN을 사용하므로 처음 열 때 인터넷 연결이 필요합니다.

## V3 변경사항

- 6자리 영문/숫자 코드 강제 검사를 제거하고, 직접 입력한 코드로 **입장과 방 생성**을 한번에 처리합니다.
- 입력한 코드가 없다면 자동으로 방을 생성하므로 별도의 방장 생성 절차가 필요 없습니다.
- 기존 `새 방 만들기` 버튼은 임의 코드 생성용으로 유지했습니다.
- 서버·클라이언트에서 코드 입력을 함께 수정했습니다. `index.html`만이 아니라 `server.js`와 `multiplayer.js`도 교체하세요.
